## 1. 의도 (왜 만드나)

제조 현장 외국인 근로자는 한국어로 된 작업지시·안전교육을 제대로 이해 못 한 채 투입되는 경우가 많다. 반장은 "알아들었냐" 물으면 "네"라는 답만 듣고, 누가 실제로 못 알아들었는지 알 방법이 없다.

이 서비스의 AI는 **번역기가 아니라 동료**다: 반장의 지시를 근로자 모국어로 쉽게 풀어주고, **진짜 이해했는지 확인 질문으로 검사해서, 못 알아들은 사람을 반장에게 알려준다.** 투입·재교육 결정은 반장이 한다.

주제 예시의 패턴("AI가 평소와 다른 답을 표시 → 최종 결정은 사람")과 같은 구조.

### 문제 근거 (조사 완료, 발표·문제정의에 사용)
- 2025 상반기 재해조사 대상 사고사망 287명 중 외국인 38명(13.2%), 노동부 "매년 10% 중반" — 뉴시스 2025-08-21
- 외국인 산재 승인 9,872명, 전년 대비 7.1% 증가, 건설·제조업 집중 — 한국경제 2026-07
- "어설픈 외국어 안전교육 해놓고 현장 투입" — 서울신문 2024-06-26
- 안전보건공단 충북북부지사: 외국인 고용 사업장 언어장벽으로 교육 어려움 — 마이데일리 2024-11-06
- 한국어 중심 교육·자막 의존 시 이해도 저하, 통역인 비용 부담 — 강남구 보도자료
- 한계: 외국인 근로자 교육 **이해도를 수치로 측정한 조사는 못 찾음** → 이 서비스가 바로 그 측정을 한다는 점을 스토리로 사용

### 기존 서비스와 차별점
- 강남구 QR 다국어 안전교육, 건설사 AI 번역앱 → 대부분 **건설현장 + 일방향 전달**
- 우리: **제조업** + **이해 확인 + 반장에게 피드백** (양방향)

## 2. 사용자

| 사용자 | 하는 일 |
|---|---|
| 반장 / 안전관리자 (한국인) | 한국어로 지시 입력, 누가 이해 못 했는지 확인, 재설명·투입 결정 |
| 외국인 근로자 | 폰으로 모국어 안내 받기, 확인 질문에 답하기 |

현장 가정: 충북 중소 제조공장 *(내 추측, 인터뷰 없음)*

---

## 3. 핵심 흐름

1. 반장: 한국어로 작업지시/안전수칙 입력 (텍스트 또는 음성)
2. AI: 근로자별 모국어 + 쉬운 말 + 그림 설명으로 변환
3. 근로자: 폰으로 받음 → AI가 이해확인 질문 2~3개 제시
4. 답이 틀리거나 이상하면 → 반장 화면에 🔴 표시
5. 반장: 재설명 요청 또는 투입 결정 (**최종 결정은 사람**)
   - 재설명 시 AI가 더 쉬운 설명 생성 → 3번으로

### 데모 시나리오 (현장 발표·시연영상용)
반장이 "프레스 작업 전 양손 버튼 동시에 누르는지 확인" 입력 → 베트남어 근로자 폰에 표시 → 확인 질문에 일부러 틀린 답 → 반장 화면 🔴 → 반장 "다시 설명" → 더 쉬운 설명 → 재답변 정답 → 🟢

## 4. AI 역할

- 번역 (한국어 → 근로자 모국어)
- 쉬운 말 변환 (전문용어 풀기)
- 그림 설명 (작업 단계 시각화)
- 이해확인 질문 생성
- 확인 질문의 보기(오답 포함) 생성 — 채점은 객관식이라 단순 비교

## 5. AI 검증 (심사 "AI 활용도" 항목 대응)

- **역번역 일치도**: 번역 결과를 다시 한국어로 → 원문과 의미 일치 비율
- **질문 품질**: 생성된 확인 질문이 원문 핵심을 담는지, 정답이 하나뿐인지 (9장 참고)
- 결과 수치표를 발표에 넣고, **한계(원어민 검수 못 함 등)를 명시**

## 9. 내 판단 (리뷰 후 정함, 사용자 확인 필요)

| 항목 | 결정 | 이유 |
|---|---|---|
| 근로자 식별·전달 | 반장이 "교육 세션" 생성 → QR/링크 → 근로자가 접속해 이름+언어 선택. 로그인 없음 | 인증 비목표, 현장에서 QR 한 번이면 끝 |
| 데모 장비 | 반장 화면(노트북) + 근로자 폰 1~2대 | 발표장에서 양쪽 동시에 보여줘야 함 |
| 지원 언어 | 언어 선택 자유(LLM이라 추가 비용 거의 없음). 데모는 베트남어, 검증은 베트남어·네팔어·영어 3개 | 범위 고정 + 검증표 크기 관리 |
| 확인 질문 형식 | **객관식(그림 보기 포함)** | 폰에서 모국어 타이핑 부담 없음, 채점 확실. AI는 질문·보기 생성 담당 |
| 🔴 조건 | 확인 질문 1개라도 틀리면 🔴 | 단순, 설명 쉬움 |
| 검증 데이터 | KOSHA 안전수칙 등에서 지시문 30건. 역번역 일치도는 LLM 판정 + 팀이 10건 직접 확인. 질문 품질(원문 핵심 포함, 정답 유일)도 같이 측정 | 객관식이라 "오답 탐지율" 대신 질문 품질로 검증 |
| 공개 배포 비용 | 호출 제한 + 같은 지시문 결과 캐싱 | 심사기간 동안 URL 공개 유지 |
